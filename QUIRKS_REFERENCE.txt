BEHAVIORAL QUIRKS REFERENCE
System Prompt Evaluation Tool - Complete Quirk Catalog

This document lists all 35 behavioral quirks detected by the quirk analyzer.
All rates are measured as occurrences per 100 words unless otherwise noted.

================================================================================
ORIGINAL QUIRK SET (11 quirks)
================================================================================

1. PARENTHESES_RATE
   Description: Parenthetical statements, asides, and clarifications
   Detection: Counts opening parentheses "(" in text
   Examples: "This is important (and relevant) for understanding."
   Trigger words: clarify, explain, detail, specify, elaborate

2. APOLOGY_RATE
   Description: Apologetic language and expressions of regret
   Detection: sorry, apologize, apologies, apology
   Examples: "I'm sorry for the confusion", "I apologize for any inconvenience"

3. QUESTION_RATE
   Description: Question marks indicating interrogative statements
   Detection: Counts "?" in text
   Examples: "Does this make sense?", "What do you think?"

4. ENUMERATION_RATE
   Description: Numbered/bulleted lists and structured enumerations
   Detection: Bullet points (-, •, *) and numbered lists (1., 2.), etc.
   Examples: "1. First step", "• Key point", "- Important item"
   Trigger words: list, enumerate, organize, structure, steps, items

5. HEDGE_RATE
   Description: Hedging words expressing uncertainty or qualification
   Detection: might, possibly, perhaps, could be, may, potentially, arguably, seems like
   Examples: "This might work", "It's possibly related to"
   Trigger words: might, perhaps, possibly, uncertain, unclear, ambiguous

6. CERTAINTY_RATE
   Description: Certainty markers expressing confidence
   Detection: definitely, absolutely, clearly, obviously, certainly, undoubtedly, always, never
   Examples: "This is definitely correct", "Clearly, the answer is"
   Trigger words: definitely, absolutely, clearly, obviously, certain, confident

7. METACOMMENTARY_RATE
   Description: Commentary about the response itself
   Detection: let me explain, I'll structure, to answer, to address, first let me, my approach
   Examples: "Let me explain my reasoning", "I'll structure this as follows"
   Trigger words: explain my approach, structure, organize, let me, I will

8. ACKNOWLEDGMENT_RATE
   Description: Acknowledgment phrases validating the user
   Detection: great question, good point, I understand, that's interesting, excellent
   Examples: "Great question!", "I understand your concern"

9. EXAMPLE_RATE
   Description: Phrases introducing examples
   Detection: for example, for instance, e.g., such as, like
   Examples: "For example, consider this case", "Such as Python or JavaScript"
   Trigger words: example, instance, illustrate, demonstrate, such as

10. ACTION_RATE
    Description: Action-oriented language and next steps
    Detection: next steps, here's what to do, action items, to get started, step \d+
    Examples: "Here's what to do next", "Action items for today"

11. CAVEAT_RATE
    Description: Caveats, qualifications, and contrasts
    Detection: however, but, although, though, nevertheless, nonetheless, yet
    Examples: "However, there's a catch", "Although this works, but consider"

================================================================================
MEASUREMENT DETAILS
================================================================================

Rate Calculation:
- Most quirks: (count / word_count) × 100
- Result: Occurrences per 100 words
- Example: 5 hedge words in 200-word response = 2.5 hedge_rate

Special Cases:
- instruction_density: (instruction_count / sentence_count) × 100
- formality_score: Composite calculation (not per 100 words)
- sentiment_polarity: Scaled 0-100 (not per 100 words)
- sentiment_subjectivity: Scaled 0-100 (not per 100 words)

Minimum Detection Threshold:
- By default, quirks with full_rate < 1.0 per 100 words are filtered out
- Adjustable via min_impact parameter in analyze_prompt_quirks()
- Lower thresholds show more subtle effects

Statistical Significance:
- Requires n ≥ 2 responses per configuration for t-tests
- With n=1: p-value always 1.0 (not statistically testable)
- Recommended n ≥ 10 for reliable significance testing

================================================================================
USAGE IN ANALYSIS
================================================================================

Leave-One-Out Testing:
1. Generate responses with full prompt (baseline)
2. Generate responses without each section (N comparisons)
3. Calculate quirk rates for each configuration
4. Identify which section causes which quirk

Attribution Logic:
- Impact = rate_with_section - rate_without_section
- Positive impact = section CAUSES the quirk
- Negative impact = section REDUCES the quirk
- Section with largest absolute impact is attributed as cause

Example:
Full prompt: hedge_rate = 5.2 per 100 words
Without section 3: hedge_rate = 1.8 per 100 words
Impact: +3.4 per 100 words
Conclusion: Section 3 causes hedging behavior

================================================================================
ADDING NEW QUIRKS
================================================================================

To add a new quirk to detect_quirks() function:

1. Define regex pattern or calculation
2. Add to quirks dictionary with descriptive key ending in _rate or _score
3. Calculate as (count / word_count) × 100 for consistency
4. Add extraction logic to extract_quirk_examples() for UI display
5. Optionally add causal explanation to generate_causal_explanation()

Example template:
```python
# NEW_QUIRK_RATE
new_pattern = r'\b(keyword1|keyword2|keyword3)\b'
quirks['new_quirk_rate'] = (len(re.findall(new_pattern, text.lower())) / word_count) * 100
```

================================================================================
LIMITATIONS & CONSIDERATIONS
================================================================================

1. Regex Limitations:
   - Simple pattern matching may have false positives
   - Context not considered (sarcasm, negation, etc.)
   - Language-specific (English only)

2. Statistical Limitations:
   - Small sample sizes (n=1) cannot test significance
   - Natural variation in LLM outputs affects reliability
   - Effect sizes may be small for subtle quirks

3. Causality Assumptions:
   - Leave-one-out assumes sections act independently
   - Interaction effects between sections not captured
   - Attribution goes to section with largest impact only

4. Measurement Granularity:
   - Per-100-words normalization may amplify small counts in short responses
   - Sentence-level detection (enumeration, instructions) sensitive to formatting
   - Word-based counting ignores semantic meaning

5. Model Variability:
   - Different models may exhibit different base rates
   - Temperature and sampling affect quirk consistency
   - Caching can reduce natural variation

================================================================================
BEST PRACTICES
================================================================================

1. Use n ≥ 10 responses per config for statistical significance
2. Lower min_impact threshold (0.3-0.5) to detect subtle effects
3. Use diverse test queries to avoid query-specific quirks
4. Compare multiple models to identify model-specific patterns
5. Validate findings with qualitative review of examples
6. Consider interaction effects when interpreting results
7. Use multiple runs to assess stability of detected quirks
